# FastAPI Practice

This is a project I'm building while learning FastAPI and backend development.

I'm using it to understand how APIs work by actually creating and testing different routes.

## What I'm learning

- FastAPI basics
- GET and POST requests
- Path parameters
- Pydantic models
- JSON data
- Testing APIs with Postman
- Git and GitHub

## Current progress

So far, I've created APIs to:
- get all posts
- get a post by its ID
- create a new post

I'm planning to keep adding to this project as I learn more about backend development.
